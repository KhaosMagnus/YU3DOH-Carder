# HISTORICAL IMPORT PLAN

## Phase A — Bootstrap
Create protocols, roles, Project State, Chat Registry, request/transfer schemas and migration inventory.

## Phase B — Forward control
All new material follows Project Control Protocol. Priority: stop creating new undocumented history.

## Phase C — Incremental historical recovery
When old material becomes relevant: locate, verify, classify, preserve provenance, link, and never overwrite history.

## Bulk migration / Codex option
Codex may inventory filenames, hash files, detect duplicates, propose mappings and extract metadata. It may NOT autonomously decide which historical draft is canonical. Owner/Project Control audits before publication.
