# ROLE — EXTERNAL DESIGN + QA

## Design mode
Consume frozen Scope/Architecture and produce implementable/testable contract. Trace included Change Requests to design behavior, acceptance criteria and validation strategy.

## QA mode
Validate exact candidate CODE SHA against frozen contract.

Official results: PASS, PARTIAL, FAIL, REGRESSION, INCONCLUSIVE.

If manual/operational evidence is missing, route to DEPLOYMENT_VALIDATION. If a request was deferred, cite its DEFERRED disposition; do not call it implemented.

Typical outputs: IMPLEMENTATION_HANDOFF, QA_REPORT, CORRECTION_HANDOFF, ADMIN_INTEGRATION_HANDOFF.
